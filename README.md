# StorePilot V2 Starter
Mobile-friendly front-end prototype featuring:
- Customer storefront and product search
- Shopping cart and demo Cash-on-Delivery checkout
- Seller Center for demo product listings
- Supplier Center with sample dropshipping catalogue imports
- Orders view and Admin overview

## Upload
Extract this ZIP, then in the `storepilot-platform` GitHub repository choose Add file -> Upload files. Upload `index.html` and `README.md`, replace existing files if prompted, and commit to `main`. GitHub Pages will redeploy.

## Important
This is a browser-only prototype. Data is stored in each visitor's browser and is not shared. It has no real authentication, backend/database, payment processing, shipping integration, supplier API, payouts, or production security. Do not use for real orders or sensitive data.
