# StorePilot Platform

StorePilot is a starter front-end demo for a marketplace concept that combines:
- Multi-vendor seller marketplace
- Supplier-based dropshipping
- Product and order management concepts

## Run locally
Open `index.html` in a modern browser.

## Upload to GitHub (mobile)
1. Open your `storepilot-platform` repository.
2. Tap **Add file** → **Upload files** (or the `...` menu if the button is hidden).
3. Select and upload `index.html` and `README.md` from this ZIP.
4. Tap **Commit changes**.

## Important
This is only a front-end starter. It does not yet include a real database, user authentication,
payments, checkout, shipping integrations, supplier APIs, or live order processing.
Those require a backend and separate implementation.
